Engineering Projects

RAG-Ops: Document Intelligence Platform

LangChain FastAPI ChromaDB Docker Kubernetes MLFlow Prometheus GitHub Actions
View on GitHub

The Objective

Build a production-grade RAG managed system that lets anyone upload a PDF and ask questions about it, backed by a complete MLOps lifecycle.

The Architecture & Deployment

Built a LangChain + ChromaDB RAG pipeline served via FastAPI, containerised with Docker, and deployed on Kubernetes with 2 replicas and readiness probes. Every query is logged as an MLflow experiment run tracking latency and retrieval metrics. Real-time observability via Prometheus and Grafana. Automated testing, linting, and Docker build on every push via GitHub Actions CI/CD.

MindVault: Multimodal Mental Wellness Monitor

Whisper librosa HuggingFace FastAPI Docker Kubernetes MLflow Prometheus
View on GitHub

The Objective

Build a passive wellness monitor that listens to how you speak, not just what you say, fusing acoustic voice signals with NLP sentiment to detect mood patterns that self-reported scores miss.

The Architecture and Deployment

Daily voice check-ins are transcribed locally via faster-whisper, then analysed with librosa for pitch, RMS energy, MFCCs, and speech rate. DistilBERT runs sentiment classification on the transcript. Both signals are fused into a composite mood score with divergence detection flagging sessions where voice energy and word sentiment disagree. Every check-in is logged as an MLflow experiment run. Real-time Prometheus metrics visualised in Grafana. Containerised with Docker, deployed on Kubernetes, CI/CD via GitHub Actions. Designed for clinical research pilots.
